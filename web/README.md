# Circle web demo

This is the mobile-first browser companion to the iOS screen-recording demo. It reuses the same local fixture photos and implements the Plan, Capture, and People flows without network calls or device permissions.

## iOS is the fixture source of truth

The web demo's people, notes, activities, calendar events, highlight reel,
palette, and asset files are generated from `ios/CircleDemo/`. Do not change
the generated files in `web/generated/` or `web/public/images/` directly.

After changing the iOS demo, run this from the repository root:

```bash
make web-sync
```

`npm start` watches `ios/CircleDemo/` and refreshes the web fixtures, assets,
and palette as you change them. Reload the browser to see the fresh content.
CI runs `make web-check`, which fails if any iOS Swift source changed without
refreshing the web output. That makes fixture and visual-source drift visible
in every pull request.

## Run locally

```bash
cd web
npm start
```

Open `http://localhost:4173`, or deploy the `web/` directory as a static site. After deployment, visit `/qr.html` on a larger screen: it generates a QR code for that site's root URL, ready for people to scan straight into the demo. The QR image is generated by QRServer; the demo itself is local and fixture-only.

The Capture scan and voice note are deliberately simulated, matching the iOS demo's fixture-only behavior.
