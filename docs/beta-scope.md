# Initial beta scope

- One user on one device.
- Up to five active friends while testing.
- One city selected by the user.
- Manual activity ideas first; at most one explicit opt-in public-events source when that adapter is added.
- Fixture mode with synthetic data is the baseline test environment.

Out of scope: contact or message import, social scraping, multi-user coordination, sync, background capture, automatic outreach, calendar changes, payments, and social discovery.
