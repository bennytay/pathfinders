# Glossary

- **Circle:** a user-created, deliberately small set of close friends.
- **Friend:** a person the user has explicitly added; never an imported contact.
- **Note:** a user-captured text reflection or optional audio reference and its editable transcript.
- **Fact proposal:** a suggested piece of context extracted from a note. It is not durable memory.
- **Confirmed memory:** user-approved, source-linked context that may be used by the planning rules.
- **Interaction:** a user-logged in-person or remote encounter. In-person is first-class.
- **Cadence:** an in-person rhythm selected by the user for a friend.
- **Prompt eligibility:** a private deterministic state calculated from configured cadence, pending plans, and snoozes. It is not a person score.
- **Prompt:** an explainable reminder a user can adjust, snooze, dismiss, or disable.
- **Activity:** a manual idea or an item returned by an opted-in event provider, including source and freshness.
- **Plan draft:** editable wording or a plan that has not been sent anywhere.
- **Privacy event:** a user-visible record of an external-processing choice, destination, and consent time.
- **Fixture mode:** a network-free workspace made only of intentionally synthetic data.
