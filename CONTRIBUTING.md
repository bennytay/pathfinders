# Contributing to InnerCircle

Thanks for helping build a more intentional, privacy-first product. The detailed setup and product-boundary rules live in [docs/contributing.md](docs/contributing.md).

## Pull request checklist

- Keep the core flow usable in synthetic, offline fixture mode.
- Do not add real personal data, recordings, secrets, or paid-service requirements.
- Update the product contract, privacy model, threat model, and ADRs when a change affects their claims.
- Run linting, type checking, unit tests, and a production build.
- Describe user-facing privacy implications and test coverage in the pull request.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
