# Security policy

## Supported version

Security fixes are applied to the latest `main` branch while this project is pre-1.0.

## Reporting a vulnerability

Please do not file public issues for vulnerabilities involving sensitive data, local storage, authentication, remote processing, or a way to cause unwanted social action. Use this repository's GitHub private vulnerability-reporting channel. If it has not been enabled yet, contact a listed maintainer privately before sharing details. Include:

- a concise description and impact;
- reproduction steps or a minimal proof of concept;
- affected commit or dependency version; and
- any mitigation you have identified.

Maintainers must enable private vulnerability reporting before a public release. We will acknowledge reports within seven days and coordinate a fix before disclosure where practical.

Never send personal notes, recordings, contacts, or production credentials in a report.
